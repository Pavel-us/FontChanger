# Font Changer

[English](README.md) · [Русский](README.ru.md)

Быстрая кросс-платформенная пакетная смена **шрифтов и размеров шрифтов** в файлах Word, Excel, PowerPoint, LibreOffice, RTF, HTML и CSS.
Написана на Rust + Tauri, интерфейс в том же стиле, что и [Text Replacer](https://github.com/Pavel-us/TextReplacer). Языки: EN/RU.

## Что умеет

Выберите папку, укажите, *что найти* и *на что заменить*, нажмите **Предпросмотр**, затем **Изменить**:

| Найти | Заменить на | Результат |
|---|---|---|
| Arial | Calibri | любой Arial становится Calibri, размеры не меняются |
| *(любой шрифт)* | Times New Roman | все шрифты приведены к одному |
| *(любой размер)* | 14 | весь текст получает 14 пт |
| 10 пт | 11 пт | растёт только текст 10 пт |
| *(любой)* + *(любой)* | Times New Roman + 14 | классическое оформление официальных документов |

Несколько правил можно собрать в список или загрузить из файла с разделителем-табуляцией.

**Шрифт и размер сопоставляются независимо.** Правило *Arial 12 → Calibri 14* меняет любой Arial на Calibri **и** любой размер 12 пт на 14 пт — оно не означает «только текст Arial размера 12».

## Поддерживаемые форматы

| Формат | Что меняется |
|---|---|
| Word `.docx .docm .dotx .dotm` | текст, стили, значения по умолчанию, колонтитулы, сноски, списки, шрифты темы |
| Excel `.xlsx .xlsm .xltx .xltm` | шрифты ячеек, форматированный текст в ячейках, примечания, надписи, шрифты темы |
| PowerPoint `.pptx .pptm .ppsx .potx …` | слайды, макеты, образцы, заметки, SmartArt, шрифты темы |
| LibreOffice / OpenOffice `.odt .ods .odp .odg` + шаблоны | все стили текста, стили по умолчанию |
| RTF `.rtf` | таблица шрифтов и размеры `\fs`; байты текста не трогаются |
| HTML / CSS `.html .htm .xhtml .css` | `font-family`, `font-size`, сокращённая запись `font`, `<font face>` (размеры записываются в пт; `@font-face` не переименовывается) |

**Не поддерживаются** (показываются как «пропущен»): PDF (текст нарисован встроенными шрифтами), старые двоичные `.doc .xls .ppt` (сначала сохраните как `.docx/.xlsx/.pptx`). В простых текстовых файлах шрифтов нет, они игнорируются.
Внутри поддерживаемых файлов не меняются: диаграммы, встроенные объекты, картинки, встроенные файлы шрифтов.

## Безопасность

- **Предпросмотр** показывает, что изменится; ничего не записывается.
- Резервные копии `.bak` (включены по умолчанию), атомарная запись (временный файл + переименование).
- **Символьные шрифты** (Symbol, Wingdings, Webdings, …) правила «любой шрифт» не трогают, поэтому маркеры и значки сохраняются.
- «Любой шрифт» меняет шрифты латиницы, кириллицы и греческого; шрифты азиатских и сложных письменностей (CJK, арабский, иврит, тайский…) остаются, пока вы не включите соответствующую опцию. Шрифт, названный явно, заменяется всегда.
- Шрифты темы тоже переписываются, поэтому текст, следующий теме, меняется тоже.
- Повреждённый или защищённый паролем файл попадает в отчёт и не останавливает работу.
- Смена шрифта или размера может изменить число страниц и вёрстку — проверяйте результат.

## Сканирование: какие шрифты есть в моих файлах?

Когда вы выбираете папку (или меняете маску), Font Changer в фоне сканирует файлы тем же разбором, которым выполняется замена, поэтому список всегда совпадает с тем, что действительно можно изменить.

- **Найден один шрифт** — он показан в поле *Найти → Шрифт* серым текстом (само поле остаётся пустым, это означает «любой шрифт»).
- **Найдено несколько шрифтов** — в поле написано «любой шрифт»; щёлкните по нему, чтобы открыть список найденного: число файлов и пометки для символьных шрифтов и других письменностей. Выбор пункта заполняет поле.
- С размерами то же самое. Строка итога показывает общие числа.
- Автосканирование можно отключить (тогда используйте кнопку **Сканировать**). Новое сканирование отменяет предыдущее.

### Откуда берётся размер

В документах бывают размеры, которых не видно на странице, поэтому список размеров делится на две части:

- **в тексте** — размер видимого текста. Только они учитываются в серой подсказке «найден».
- **не видны в тексте** (серые) — размеры, которые есть только **в стилях** (значения по умолчанию, описания стилей, уровни списков, образцы слайдов) или **скрытые** (знак абзаца ¶, пустые фрагменты, пробелы, табуляции). Знак абзаца в 1 пт — типичный способ сделать тонкую строку-разделитель.

Под найденными размерами список предлагает ещё типовые размеры и шрифты, поэтому он работает и при выключенном сканировании. Название вроде `inherit` (остаётся после копирования с веб-страницы) помечается «некорректное имя».
В Excel все размеры ячеек считаются «в тексте»; для HTML и CSS формат не говорит, где размер, поэтому они тоже считаются текстом.

**Защита мелких размеров.** «Любой размер → X» по умолчанию не трогает размеры **меньше 6 пт** (настройка в боковой панели, 0 — выключено), чтобы строки-разделители сохранили высоту. Правило с явно указанным исходным размером (например, `1 → 2`) действует всегда.

## Шаблоны правил (`.fctpl`)

**Сохранить правила…** записывает список правил (или заполненные поля) в файл `.fctpl`; **Загрузить правила…** читает его обратно вместе с маской и двумя опциями, влияющими на результат (символьные шрифты, другие письменности). Файл `.fctpl` — обычный JSON:

```json
{
  "format": "fctpl",
  "version": 1,
  "name": "official-docs",
  "mask": "*.docx",
  "options": { "keepSymbols": true, "scripts": false },
  "rules": [
    { "fromFont": "Arial", "toFont": "Calibri", "fromSize": "", "toSize": "" },
    { "fromFont": "", "toFont": "Times New Roman", "fromSize": "", "toSize": "14" }
  ]
}
```

Пустая строка означает «любой» (слева) или «не менять» (справа). Неизвестные поля игнорируются, а файлы с более новой `version` отклоняются с понятным сообщением.
Старые файлы правил с табуляциями (`исх. шрифт ⇥ нов. шрифт ⇥ исх. размер ⇥ нов. размер`, `#` — комментарий) по-прежнему загружаются.

## Сборка

```
npm install
npm run dev            # запуск
npm run test           # проверка переводов + тесты движка (cargo test)
npm run build          # установщики
```

Нужны Rust, Node.js 18+ и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/).

## Установка на Linux (Linux Mint и другие)

Программа появляется в меню приложений в разделе **Офис**.

- **.deb (рекомендуется):** `npm run build:deb`, затем `sudo apt install ./src-tauri/target/release/bundle/deb/*.deb`. Вместе с пакетом ставятся пункт меню, значок и категория «Офис», а `sudo apt remove font-changer` удаляет программу.
- **AppImage:** `npm run build:appimage`, затем `scripts/install-appimage-linux.sh "src-tauri/target/release/bundle/appimage/<файл>.AppImage"` копирует файл в `~/.local/share/font-changer` и добавляет пункт меню (root не нужен). `scripts/install-appimage-linux.sh --uninstall` убирает его.

Если пункт не появился сразу, перелогиньтесь или выполните `update-desktop-database ~/.local/share/applications`.

## Релизы и автообновление

Как в Text Replacer: workflow релиза подписывает пакеты обновления ключом `TAURI_SIGNING_PRIVATE_KEY`.
В `src-tauri/tauri.conf.json` сейчас лежит **тот же публичный ключ, что и у Text Replacer**, поэтому можно использовать тот же приватный ключ как секрет репозитория.
Чтобы завести отдельный ключ: `npx tauri signer generate -w ~/.tauri/fontchanger.key`, затем `node scripts/set-updater-key.mjs ~/.tauri/fontchanger.key.pub`.
Если измените `app-icon.png`, пересоберите иконки командой `npm run icons`.

## Языки

Интерфейс доступен на английском и русском. Язык можно добавить **без пересборки**: откройте меню с шестерёнкой и нажмите 📂 — откроется папка для своих переводов (`locales` внутри папки настроек приложения, например `~/.config/dev.fontchanger.app/locales` в Linux). Положите туда файл `<код>.json` (возьмите за образец [`src/locales/en.json`](src/locales/en.json) и задайте `_meta.code` и `_meta.name`) и перезапустите программу. Файлы, имена которых начинаются с `_`, игнорируются. Чтобы добавить перевод в проект, см. [CONTRIBUTING.md](CONTRIBUTING.md).
